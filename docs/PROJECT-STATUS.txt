【一、项目概述】

AsterTrack 是分布式 eBPF EDR 系统。
  - Agent：Go + eBPF（5 探针），部署在被监控主机
  - Server：Go + PostgreSQL，中央管理 + 关联分析
  - 前端：Vue3 + naive-ui

核心能力：
  - 探针采集（exec/file/bash/tcp/xdp）
  - 星轨关联（攻击链追踪）
  - 动态规则（敏感路径下发 + 签名）
  - 自检机制（探针健康）

架构分层：
  C 层（eBPF）    → 采集 + 内核态过滤
  Agent 层（Go）  → 血缘 + 关联 + 上报
  Server 层（Go） → 关联分析 + 规则 + 存储
  前端（Vue）     → 可视化

【七、关键约定】

1. SPIFFE 域名冻结：spiffe://astertrack/agent/<id> 不能改
2. 时间常量集中：agent/internal/agent/constants.go
3. 路径统一：用 paths.Join(...)
4. 品牌统一：用 internal/brand
5. DB migration：必须用 sentinel 用户执行 + 末尾加 GRANT
6. go build ./... 只检查语法，要 -o 生成二进制
7. certs/ 和 agent/data/ 是 gitignore
8. execve 的 filename 是占位符，真实命令在 details
