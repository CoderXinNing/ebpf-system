【零、项目概述】

  AsterTrack 是分布式 eBPF EDR 系统。
    Agent：Go + eBPF（5 探针），部署在被监控主机
    Server：Go + PostgreSQL，中央管理 + 关联分析
    前端：Vue3 + naive-ui

  架构分层：
    C 层（eBPF）    → 采集 + 内核态过滤
    Agent 层（Go）  → 血缘 + 关联 + 上报
    Server 层（Go） → 关联分析 + 规则 + 存储
    前端（Vue）     → 可视化
